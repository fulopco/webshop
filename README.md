# Webshop Application

This project is a simple webshop application with a Java-based backend and a React-based frontend.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data
- Spring Security
- RESTful API
- Hibernate (JPA)
- PostgreSQL

### Frontend
- React
- JavaScript
- REST API integration

## Features
- User authentication and authorization
- Product management
- Order handling
- Secure REST endpoints
- Persistent data storage with PostgreSQL

## Architecture
- Backend exposes REST APIs using Spring Boot
- Frontend consumes APIs via HTTP
- Database access handled via Hibernate/JPA
- Security implemented with Spring Security

## Database
- PostgreSQL
- ORM: Hibernate

## Getting Started

### Backend
1. Configure PostgreSQL connection in `application.yml` or `application.properties`
2. Run the Spring Boot application

### Frontend
1. Install dependencies with `npm install`
2. Start the application with `npm start`
